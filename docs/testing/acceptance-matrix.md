# Mo' Bends 功能验收矩阵

> 本矩阵描述当前独立维护版本的可见功能和验收口径；行内参考状态不是当前 PASS 证据。

## 1. 范围与判定口径

- 原版事实基线：上游 `v1.2.2`（`1.X/forge-1.12`，提交 `0508765b3a9066d0eb8124fbe771a0ca4600f637`）的全部受版本控制代码与资源。
- 当前被测目标：唯一 implemented Target `fabric-26.2`，使用
  `run/fabric-26.2/client` 内的兼容世界。其余四个 Target 为 planned，不进入当前验收。
- 本表只覆盖原版中已经完成、用户可到达且能观察结果的本地功能。远程联网、下载、支持者同步、公共数据库、在线包页和外部动画编辑器均不在范围内。
- 原版中只有占位或不可到达的代码不计为功能：Packs 页的 `Coming soon`、无实现的创建包操作、被注释的 Add-ons 按钮、未实现的驱动层、未接入的文本框裁剪、已整段注释且不再使用的旧攻击位。
- 当前 `PASS` 必须来自本次实际运行的 framebuffer 截图/帧网格，并能辨认预期姿势、过渡或
  设置结果；仅有源码审查、日志、命令成功或实体存在都不能判为视觉通过。本表的 `BASELINE`
  只表示该行为和判定口径具有历史参考证据，仍需当前 Fabric 代码实际复验后才能记为 PASS。
- 连续动作以帧网格为主，静态姿势/UI 以单帧为主。无法由自动化稳定触发、画面被遮挡或证据不足时记 `BLOCKED`，观察到缺陷记 `FAIL`。

## 2. 实例隔离与测试边界

| 项目 | 固定值 / 规则 |
| --- | --- |
| Mo' Bends DebugBridge | 为 `fabric-26.2` 显式分配空闲端口，并把端口、Target、gameDir 与 PID 写入本轮外部会话清单 |
| 身份核验 | Minecraft 与 Loader 必须匹配 Target；gameDir 必须精确等于 `run/<target>/client` |
| 禁止接触 | 不自动发现、不连接、不终止未登记在本轮会话清单中的进程、端口、窗口、世界或文件 |
| 客户端 | 只启动 `fabric-26.2`；四个 planned 目标不得启动 |
| 世界改动 | 只在 `x=1960..2088, y=96..132, z=1960..2088` 建造，使用 `MOBENDS_VA_*` 名称标识测试实体 |
| 配置改动 | 测试前备份 `config/mobends-client.json`；测试后恢复原值。测试包只放在本实例 `bendspacks/MOBENDS_VA_*` |
