# 动画与配置

适用于 Minecraft 1.20.1 Forge、1.21.1 NeoForge、26.1.2 NeoForge、26.3 NeoForge 和 26.3 Fabric。

你可以启用玩家、僵尸、骷髅、僵尸猪灵、蜘蛛、鱿鱼及狼的分段动画，调整物品动作、轨迹和各实体开关。关闭实体动画后应使用原版模型。

## 配置入口

NeoForge 的模组列表提供配置入口；Fabric 使用 Mod Menu 打开 Mo' Bends 配置。Mod Menu 是可选的菜单集成，不是普通玩家必须安装的产品依赖。

## 本地动画包

在配置页面进入本地 BendsPack 页面，选择动画包并调整顺序。列表前面的包优先。本地文件变动由包页面监测；本项目不提供远程包数据库、支持者身份或远程下载。

## 当前限制

版本构建成功不代表所有动作和装备组合已验收。现有泳姿、披风、装备覆盖及包异常处理的审计问题仍待后续修复。
