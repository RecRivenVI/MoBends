# 上游行为参考

只读行为基线为上游 `1.X/forge-1.12` 的 `v1.2.2`，提交
`0508765b3a9066d0eb8124fbe771a0ca4600f637`。上游用于解释历史语义，不决定当前仓库身份、
Target 结构、工具链或维护者。

## 保留的可见语义

- 玩家、僵尸、骷髅、僵尸猪灵、蜘蛛、鱿鱼和狼七类 Bender；
- 站立、行走、疾跑、潜行、跳跃、游泳、攀爬、骑乘、睡眠、飞行和鞘翅姿态；
- 进食、饮用、弓、盾、工具、拳击、剑连段和警戒姿态；
- 手持物、头戴物、盔甲、披风、鞘翅、剑刃拖尾和箭矢拖尾；
- 本地 BendsPack、KUMO 条件、Addon 生命周期和服务端策略；
- 水下攻击或拉弓后的近直立动作准备分支；
- 箭矢轨迹只跟随飞行段，落地或失效后清理。

现代 Minecraft 新增的十字弩、三叉戟/长矛、望远镜、山羊角和刷子采用目标版本原版第三人称
手臂语义；未知使用动作保持普通持物或第三方原版姿势，不误判为进食。

## 不属于当前功能的上游内容

支持者身份、远程饰品、公共包数据库、在线搜索与下载、远程玩家设置和外部动画编辑器不进入
当前实现。只有占位、空回调、`Coming soon` 或整段注释的入口也不被视为已完成功能。

## 参考边界

独立维护允许根据可观察行为和历史契约修复实现，但不得删除原始许可和版权归属。五个当前声明
的 Target，其 API、GUI 和渲染差异以各自 Minecraft 源码和真实运行证据为准；planned Target
在重新激活前不具有当前运行证据。
